Welcome to tt.tt, a lightweight task manager that helps you organise your tasks and deadlines.

## Adding deadlines

Add a deadline to a task by including a date in the format `YYYY-MM-DD`. This helps you keep track of tasks that need to be completed by a specific date.

Use the `deadline` command followed by a task description and date to record when the task is due.

Example: `deadline Return library book /by 2026-09-15`

## Sorting tasks

Use `sort` to arrange every task alphabetically by its description. Sorting ignores capitalization and saves the new
order, so your tasks remain sorted the next time you open tt.TT.

For example, if your tasks are `write report`, `Buy milk`, and `call Alice`, enter:

```text
sort
```

tt.TT responds with:

```text
Here are your tasks sorted alphabetically:
1. [T][ ] Buy milk
2. [T][ ] call Alice
3. [T][ ] write report
```
